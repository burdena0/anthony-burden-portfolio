# Anthony Burden

Personal engineering portfolio: [burdena0.github.io](https://burdena0.github.io).

Projects in robotics, computer vision, and embedded systems, with experience and a downloadable resume.

## Development

```sh
node build.mjs
python -m http.server 4173 --directory dist
```

Edit project details in `projects.mjs`, the homepage in `build.mjs`, and styling in `dist/styles.css`. Media and the resume live in `dist/assets/`.

The site uses static HTML, CSS, and system fonts. It has no browser JavaScript or external runtime dependencies. Pushes to `main` build and deploy through GitHub Pages.

## Project media

The Webots images and MuJoCo recording are saved simulation outputs from the linked projects. Results and testing limitations are described on the project pages.

Camera simulation geometry is adapted from [Turret Mechanism by PJohnso1](https://www.thingiverse.com/thing:4259522), licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
